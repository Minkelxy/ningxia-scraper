## 原文内容

站内景点、路线、城市、专题和美食图片优先采用可追溯的网络实拍照片。每张图片在数据中保留作者、许可类型和原始页面，页面只在照片确实对应时使用“实景”表述；参考图会在替代文本中说明范围，不把参考照片当成具体商户、菜品规格或景区内部游线的证明。

## 使用规则

- 景点图片优先对应具体景点；无法确认精确位置时，替代文本使用“实景参考图”，不写成该景点的直接证明。
- 美食图片优先对应菜品或食材；没有找到完全对应的公开照片时，使用同类实拍参考图，并在替代文本中说明。
- CC BY、CC BY-SA 和 CC0 图片保留作者与原始页面；政府网站公开图片保留发布机构和来源页面。
- 需要裁切、压缩或生成响应式版本时，只改变文件规格，不改变照片内容和来源记录。
- 价格、营业、开放和交通等信息仍以内容来源和出发前公告为准，图片不承担这些字段的核验职责。
